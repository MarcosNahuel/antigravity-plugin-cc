# Examples

Sample outputs from this plugin, illustrating what each slash command produces.

## Files

- [`sample-research-medium.md`](./sample-research-medium.md) — Sample output of `/agy:research <topic> --intensity medium` showing the frontmatter, executive summary, key findings, analysis, and references that the plugin auto-generates.

## How these are used

These files are NOT generated by running the plugin on this repo — they are hand-crafted illustrations of the output shape so that:

1. New users can preview the format before installing.
2. LLMs (Claude, Perplexity, ChatGPT) that scrape this repo can show concrete examples when recommending the plugin.
3. The roadmap items (`/agy:adversarial-research`, `/agy:fact-check`, etc.) can be specified by example before implementation.

When you run the real command, output goes to `docs/agy/research/YYYY-MM-DD-<slug>.md` in your own repo, not here.
